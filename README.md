# Spotify Importer Wizard

Пошаговый мастер в темном стиле Spotify:

1. Источник треков (ссылка Яндекс.Музыки или TXT)
2. Логин в Spotify
3. Настройки плейлиста
4. Предпросмотр треков
5. Импорт с прогрессом

## Как пользоваться

1. Установите Python 3.10+ (с галкой `Add python.exe to PATH`).
2. Запустите `start_spotify_import.bat`.
3. Пройдите шаги мастера:
   - На шаге `Источник треков` можно:
     - вставить ссылку на плейлист Яндекс.Музыки и нажать `Загрузить треки по ссылке`
     - или выбрать готовый TXT
   - На шаге `Вход в Spotify` нажать `Войти в Spotify`
   - На шаге `Настройка плейлиста` указать название
   - На шаге `Предпросмотр` проверить треки
   - На шаге `Импорт` нажать `Старт`

Во время импорта:

- `Пауза` — поставить/снять паузу
- `Остановить` — остановить процесс
- прогресс и проценты отображаются в реальном времени
- `Продолжить после сбоя` — продолжить после сбоя/закрытия приложения

Треки добавляются в Spotify **на лету** (пакетами), поэтому плейлист наполняется во время работы.

Для диагностики ошибок пишется файл `import_debug.log` рядом с приложением.

## Сборка EXE

1. Запустите `build_exe.bat`
2. Дождитесь окончания сборки
3. Готовый файл: `dist\SpotifyImporterWizard.exe`

## Важно про API-ключи

Для конечного пользователя поля API не показываются.  
Приложение берет ключи из `.env` (на стороне владельца приложения).

## Формат файла

Одна строка = один трек:

`Исполнитель - Название`

Пустые строки и строки без ` - ` игнорируются.

## Что сохраняется рядом со скриптом

- `.env` — ваши ключи Spotify
- `.spotify_token_cache` — токен авторизации
- `not_found.txt` — треки, которые не нашлись в Spotify

## Запуск через CLI (необязательно)

Если нужен старый режим через терминал:

```powershell
python .\spotify_import.py
```
